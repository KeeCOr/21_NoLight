INKWARRIOR GDD 초안

문서 날짜: 2026-09-11 / 게임 버전: v0.14.1 (브라우저/Electron)

문제 정의 / 페르소나 / 코어 루프

  • 문제: 흑백 잉크 비주얼 안에서도 액션의 타격감과 리듬을 명확히 전달하는 방법.
  • 페르소나: 콤보/타격감 중심 액션 게임을 선호하는 플레이어.
  • 코어 루프: 플랫폼 이동(레인/점프/드롭스루) → 적/추격자 조우 → 스태미나 소모 공격(전기 캐릭터/메카암) → 콤보/임팩트 연출 → 체력 드랍 회수 → 다음 구간 진행.

MVP / KPI / 레퍼런스

  • MVP: 스태미나 공격 비용, 샤크 전투, 플랫폼 레인/점프/드롭스루, 맵 생성기, 체력 드랍, 콤보/임팩트/카메라/오디오/HUD, 광범위한 테스트 존재.
  • KPI: 수치 미정.
  • 레퍼런스: 잉크 모노크롬 아트 방향의 액션 게임(구체 타이틀 미확인).

필러 / 컴포넌트

필러 컴포넌트
타격의 리듬 콤보/임팩트/카메라
자원 관리 긴장 스태미나 공격 비용
위협의 다양성 적/추격자/샤크 전투
이동의 자유 플랫폼 레인/점프/드롭스루
생존 피드백 체력 드랍/HUD/오디오

사실 / 미확인

  • 확인: 엔티티(전기 캐릭터, 메카암, 적, 추격자), 위 시스템, 테스트 다수 존재.
  • 미확인: 스테이지 구성 수, 난이도 곡선 수치, 콤보 밸런스 수치.

페이싱 및 재미 사슬 (예시 2개)

  1. 이동 구간(레인/점프) → 적 조우 → 콤보 연계 → 임팩트/카메라 강조 → 처치.
  2. 추격자 등장 → 긴장된 드롭스루 회피 → 스태미나 소모 압박 → 체력 드랍 획득 → 위기 극복.

피로도

  • 연속 전투로 인한 스태미나 관리 피로 가능 — 체력 드랍/휴식 구간으로 완화(계획/제안).

경제

  • 스태미나가 핵심 자원이나 세부 회복/소모 수치 미확인.

온보딩

  • 별도 튜토리얼 여부 미확인(제안: 레인 이동/드롭스루 조작 튜토리얼).

HUD 5가지 상태

  1. 평상 이동 2. 전투 중(콤보 게이지) 3. 스태미나 부족 경고 4. 피격/체력 위험 5. 게임오버

접근성

  • 모노크롬 비주얼 특성상 색약 이슈는 적을 가능성이나 대비/모션 감도 옵션 미확인(제안: 카메라 임팩트 강도 조절 옵션).

AV: 구현/계획/제안

  • 구현: 콤보/임팩트/카메라/오디오/HUD.
  • 계획: 미확인.
  • 제안: 추격자 등장 시 전용 오디오 스팅어, 잉크 이펙트 강도 옵션.

우선순위 3

  1. 스태미나 공격 비용 밸런스 검증
  2. 추격자/샤크 전투 난이도 곡선 점검
  3. 맵 생성기 구간 다양성 확대

구성요소

역할 선택 입력→판정→피드백 상태
electric (플레이어 유닛) 유닛 선택 가능 여부 미검증 이동·공격 입력 → 스태미나 소모/충돌 판정 → 콤보 카운트·체력 변화 피드백 구현됨
mecha (플레이어 유닛) 유닛 선택 가능 여부 미검증 상동 구현됨
pursuer (추격형 적) 선택 불가(AI, 미검증) 추격 로직(AI 입력) → 플레이어 접촉 판정 → 체력 감소 피드백 구현됨(AI 세부 로직 미검증)
enemy (일반 적) 선택 불가 스폰/배치 → 공격 판정 → 피격 이펙트·체력 드랍 피드백 구현됨

콘텐츠 제공 방식

플랫폼(platforms)·맵(map) 구조 기반 스테이지 진행으로 추정(구체적 언락/배포 방식 미검증). 체력 드랍(health drops) 아이템을 맵 상에 배치해 자원 제공.

세션 구조

30초

기본 이동/공격 입력 및 스태미나 반응 확인 — 온보딩 유무 미검증

5분

플랫폼 구간 통과, 적/pursuer 조우 및 콤보 시도 — 미검증

30분

다중 스테이지/맵 반복, 체력 관리 루프 — 미검증

장기

진행도 저장, 난이도 곡선 등 장기 리텐션 요소 — 미검증(현재 확인된 장기 루프 없음)

구현됨 / 계획됨 / 제안

  • 구현됨: 액션 플랫폼 이동, electric/mecha/pursuer/enemy 엔티티, 스태미나 기반 공격, 플랫폼/맵, 체력 드랍, 콤보·카메라·오디오 HUD
  • 계획됨: 미검증(로드맵 문서 확인 안 됨)
  • 제안: 콘텐츠 제공 방식(스테이지 언락 구조) 및 세션 구조(5분~장기) 명문화

성공 KPI

미검증 — 확인된 지표 없음 (제안: 콤보 유지시간, 스테이지 클리어율, 평균 세션 플레이타임)
