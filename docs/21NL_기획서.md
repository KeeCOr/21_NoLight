# InkWarrior 기획서
> 현재 문서 기준 버전: 0.12.0

![InkWarrior gameplay preview](./21NL_gameplay_preview.png)

## 현재 구현 상태
- 현재 문서 기준 버전: 0.11.0
- Phaser 3 + Electron portable 구조를 유지한다.
- ActionFeedback은 strike, evade, wound, finish, failure 피드백을 관리하고 각 피드백에 Kenney CC0 SFX cue를 포함한다.
- GameScene은 ActionFeedback의 anchor, layer, timeline, densityCue, sfx cue를 사용해 첫 30초 전투 피드백을 표시하고 재생한다.
- CameraImpactProfile 순수 규칙으로 기본 히트, 콤보, 처치, 스킬, 추격 카메라 반응을 관리한다.
- UI 디자이너 후속 작업 목록은 docs/ui-designer-camera-impact-tasks.md에 유지한다.
