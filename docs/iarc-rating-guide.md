## Violence

| Question | Answer | Notes |
|----------|--------|-------|
| Does the game contain violence? | **Yes — Mild / Stylized** | Action platformer with melee combat; attacks shown through ink-brush VFX |
| Is the violence realistic? | **No** | All combat effects are stylized brushstroke visuals; no anatomical detail |
| Does the game depict blood? | **No** | Ink mechanics use dark ink effects that are distinct from blood depictions |
| Does the game contain graphic depictions of injury or death? | **No** | Defeat is shown through an ink burst / dissolve VFX; no graphic imagery |
| Is violence directed at specific real-world groups? | **No** | All combatants are fictional characters in a stylized world |
| Is there torture or sadistic violence? | **No** | |

**Summary:** Stylized melee combat expressed through ink-brush VFX. No blood, no gore, no realistic violence. The "ink wound" effect (`blood ink` in internal docs) is a visual design choice using dark ink tones, not a depiction of real blood.

## Notes for Submission

- The game is a **singleplayer, offline** Windows title.
- All content is self-contained; no online features, no user communication, no IAP.
- When describing violence type in the IARC tool, select: **"Animated / cartoon / fantasy violence"** and **"No blood or gore."**
- The ink aesthetic may raise questions from reviewers unfamiliar with the visual style. If a clarification field is available, note: *"The game uses ink-brush visual effects to represent combat. Dark ink effects simulate impact and damage but do not depict blood, anatomical injury, or graphic violence of any kind."*
- The internal VFX descriptor "blood ink" in development documentation refers to a dark-toned ink splash effect used for player damage feedback — it contains no imagery that resembles or references real blood.
